= Creating your own diagrams

In a gradle project, if you're using asciidoctor for documentation, you can generate diagrams using `grooves-diagrams`.

[source,kotlin,subs="attributes+"]
----
import org.asciidoctor.gradle.model5.jvm.extensions.AsciidoctorjGenericExtension
import org.asciidoctor.gradle.model5.jvm.toolchains.AsciidoctorjToolchain

plugins {
    id("org.asciidoctor.jvm") version "5.2.0" // <1>
}

repositories {
    mavenCentral()
}

asciidoc.toolchains.named<AsciidoctorjToolchain>("asciidoctorj") {
    useAsciidoctorj("3.0.1")
    asciidocExtensions.register<AsciidoctorjGenericExtension>("groovesDiagrams") {
        useModule("com.github.rahulsom:grooves-diagrams", "{gradle-project-version}") // <2>
    }
}

asciidoc.publications.named("main") {
    output("asciidoctorj", "html") // <3>
}
----
<1> Apply the Asciidoctor Gradle plugin.
<2> Add the Grooves diagram extension to the AsciidoctorJ toolchain.
<3> Enable HTML rendering with the `asciidoctorHtml` task.

Now in your asciidoctor files, you can do this

[source,asciidoctor]
----
[esdiag,SimpleEvents]
....
|Type,ID,Description
  + 1 2016-01-02 created as John Lennon
  + 2 2016-01-03 performed FLUSHOT for $ 32.40
  + 3 2016-01-04 performed GLUCOSETEST for $ 78.93
  + 4 2016-01-05 paid $ 100.25
....
----

The result is this

[esdiag,SimpleEvents]
....
|Type,ID,Description
  + 1 2016-01-02 created as John Lennon
  + 2 2016-01-03 performed FLUSHOT for $ 32.40
  + 3 2016-01-04 performed GLUCOSETEST for $ 78.93
  + 4 2016-01-05 paid $ 100.25
....

Take a look at https://github.com/rahulsom/grooves/tree/main/grooves-docs/src/docs/asciidoc[the source] for more examples of creating diagrams.
